## 📌 專案背景與解決痛點
近年來極端氣候與氣候變遷加劇，暖冬、乾旱與短時強降雨等異常天象頻繁打亂果樹生長節奏，傳統「看天吃飯」的經驗已難以應對，導致果農常錯失最佳防護時機。然而，一般氣象預報僅提供未來幾天的天氣概況，缺乏**「今年與歷年同期相比」**的量化基準。

為解決此痛點，本系統串接**政府開放資料（中央氣象署 Open Data API）**，自動整合鄰近測站的即時氣象觀測與歷年同期氣候基準，將冷冰冰的氣象數字轉化為直覺的異常預警與果園管理行動建議。

---

## ✨ 核心功能與分析指標

1. **即時與歷年同期自動比對（Month-to-Date 校正）**
   * 支援臺中東勢、新社、和平（梨山）、霧峰及苗栗卓蘭等主要果園產區測站。
   * 依據當月經過天數比例動態校正累積雨量基準，避免月初與全月基準比較產生失真。
2. **三大關鍵農業氣象指標運算**
   * **月均溫偏差（$\Delta T_{\text{mean}}$）**：評估暖冬效應（休眠不足、花期紊亂）或低溫寒害風險。
   * **累積雨量異常比（Rainfall Anomaly %）**：辨識乾旱缺水或連續豪雨引發的根系缺氧、裂果與真菌病害。
   * **日夜溫差（DTR）監測**：掌握果實轉色與糖度累積黃金期，同時防範水分劇烈波動造成的生理裂果。
3. **果園行動決策建議引擎（Actionable Advisories）**
   * 依據指標異常等級（正常、注意、警戒），自動生成灌溉、排水清淤、套袋保溫與預防性噴藥等田間管理建議。
